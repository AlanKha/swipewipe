Duplicates

Each set is photos with the exact same file size and date taken. These usually come from re-imports such as a Google Photos migration, which leave a copy named like IMG_1234(1).JPG next to the original.

In every set SwipeWipe suggests keeping the original (the name without “(1)”) and binning the copies. Click any photo to switch it. Nothing is deleted here: binned photos go to Review bin first.
